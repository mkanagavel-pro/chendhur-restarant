# Chenthur Restaurant — Vercel Ready

## Included
- `index.html` — responsive restaurant website
- `assets/chenthur-live-kitchen.mp4` — supplied 10-second cooking video used in the Live Kitchen section
- `vercel.json` — static deployment configuration

## Deploy to Vercel
1. Extract this ZIP.
2. Create a new GitHub repository.
3. Upload the contents of this folder to the repository root (make sure `index.html`, `vercel.json`, and the `assets` folder are at the root).
4. In Vercel, choose **Add New → Project**, import the repository, choose **Other** as the framework preset, leave Build Command blank, set Output Directory to `.` and deploy.

The cooking video is served locally from this project rather than an external stock-video URL. Food photos elsewhere on the page still use external Unsplash URLs and require internet access.

Note: Confirm restaurant menu, actual dishes, operating hours, and photos with the owner before using this as an official live business website.
